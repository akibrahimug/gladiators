For each future gate, create a record using the template. Keep evidence relative to the project or point to an authorised accessible source; record hashes/versions for datasets and reports. Avoid placing account credentials or private account exports in this workspace.

## Expected record

A gate record identifies baseline and source manifest; requirements/components; upstream gate versions; exact acceptance criteria; evidence paths and checksums; outcomes and limitations; unresolved issues; owner/reviewer; decision/date; and downstream gates to reopen on a change.

A reviewer must be able to distinguish **planned evidence**, **observed result** and **accepted result**. A source document or a completed checklist cannot stand in for an executed reconstruction/replay/simulation result.

No empty placeholder result is counted as passing evidence. Numeric performance thresholds must be agreed before measuring them for acceptance.
