# IDE navigation

[Project home](../README.md) · [Documentation index](README.md)

Open the project file **GLADIATOR.code-workspace** in Cursor, or open the GLADIATOR folder in your preferred IDE. Start at the root README, then the documentation index.

For implementation handoff, start Claude Code in this folder, where [CLAUDE.md](../CLAUDE.md) is located. Follow the [task board](tasks/README.md) and [workflow](working-with-claude.md). Restart an existing Claude Code session to discover this project's newly created agents directory. Agent/runtime discovery and PR access remain to be verified in Claude.

- Follow relative Markdown links to move between phases, requirements, components and gates.
- Search for a stable ID such as `REQ-006`, `CMP-04` or `G03` to see every related document.
- Use the [full catalog](catalog.md) to find all Markdown documents and preserved source records.
- Use the IDE's Markdown preview for tables and diagrams; the adjacent text/tables provide navigation if diagram rendering is unavailable.
- Edit planning documents under `docs/`; preserve imported originals under `docs/sources/originals/`.

The workspace enables text wrapping and UTF-8 files. It contains no executable task, dependency installation, recommended extension installation, application launcher task or trading configuration.

If original v1.0 files arrive, follow [source intake](sources/originals/README.md), then update the [matrix](traceability/requirements-matrix.md) and [catalog](catalog.md). Do not overwrite an original to make a link or heading prettier.
