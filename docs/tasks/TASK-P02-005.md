## Objective and observable result

Build the network side, using the standard library only (DEC-062):
- `transport.py`: HTTPS GET and HEAD, a robots check and header capture;
- `ws.py`: a minimal WebSocket client;
- `live.py`: a Kraken v2 `book` (depth 10), `trade` and `status` capture. Every frame is journalled before parsing, the book checksum is verified, and the book is resubscribed on a mismatch or reconnected after a disconnect;
- `cli.py`, with the launcher `capture.py`: the `head`, `live` and `daily` commands;
- a launchd template for the 30-day pull (DEC-061).

Then make the authorised calls: the 18 Binance HEAD requests, and a 1-hour live capture (W-J). Record the results in [network-capture.md](../evidence/P02/network-capture.md).
