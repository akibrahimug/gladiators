**No original GLADIATOR specification has been imported.** This directory currently contains intake documentation only. The latest v1.0 architecture and original Markdown specification bodies remain missing (SRC-003), so the baseline gate G00 is pending.

When the original files or full conversation exports become available, copy them here byte for byte. Preserve original filenames, directory relationships, version headers and attachments. If only a message body is recoverable, save the exact retrieved body and its source message ID; identify it as a message extraction rather than claiming it is an original Markdown file. Preserve the raw export separately when available.

Do not edit imported originals to repair spelling, reorganize headings, update links, remove conflicts or conform to the new plan. Put any normalized or reconciled document elsewhere and link it to the preserved original. Keep successive or conflicting versions in distinct paths so no source is overwritten.

Every original must appear in the [import manifest](import-manifest.md) with a SHA-256 digest, provenance, version evidence, supersession evidence and links to its requirements, phases and components. Use the [intake checklist](intake-checklist.md) to reconcile the complete set before considering G00 ready for review. A filename containing `v1.0` is a version claim to check against the contents and provenance, not sufficient evidence by itself.
