## Preservation and scope

10 distinct ZIP archives and all 405 contained files are preserved. Original filenames, directory structures and bytes are unchanged. Duplicate downloads with identical ZIP hashes are represented once. Each archive and member has a SHA-256 digest in the inventory.

The original archives contain offline prototype Python files and bytecode. They are preserved only under this source archive; no imported code was executed, installed or wired into the application. No live trading is enabled.
